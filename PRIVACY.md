# Privacy Perimeter

This repository must not contain private or sensitive material.

Forbidden material includes:

- secrets, tokens, passwords, private keys, certificates, recovery codes
- `.env` files except inert examples such as `.env.example`
- private customer, employee, vendor, logistics, financial, or identity data
- production logs, raw telemetry, raw exports, databases, dumps, backups
- unreleased private manuals, internal operating instructions, hidden governance notes
- infrastructure credentials, cloud configs, kubeconfigs, Terraform state
- proprietary third-party data not licensed for public release
- screenshots exposing private systems, emails, accounts, dashboards, addresses, phone numbers, or personal identifiers

Public artifacts must be intentionally generated, deterministic where possible, and safe for public readback.
