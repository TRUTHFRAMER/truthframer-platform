
# TRUTH_FRAME Standard

A `TRUTH_FRAME` is the atomic object of TRUTHFRAMER.

It is not a screenshot, chart, dashboard, post, or opinion.

A `TRUTH_FRAME` is a replayable market-structure object that binds source, clock, venue state, structural measurements, visual projections, and interpretation boundaries.

## Required properties

* frame identity
* replay window
* source manifest
* clock policy
* market scope
* truth layers
* visual projections
* replay declaration
* boundary declaration

## Non-negotiable rule

A visual projection is inadmissible unless it is backed by a `TRUTH_FRAME`.
